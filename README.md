Personal portfolio — **Fahrur Anshori, Fullstack & Mobile Developer**: web apps, REST APIs,
and mobile development.

## Sections

- **About** — intro & background

- **Projects** — selected work

- **Contact** — get in touch

## Tech

- React 19 + TypeScript + Vite
- GSAP + Lenis (animations & smooth scrolling)
- Tailwind CSS 4
- React Router

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (default [http://localhost:5173](http://localhost:5173)).

## Production build

```bash
npm run build
npm run preview
```

## Tests

```bash
npm test          # unit tests + E2E tests
npm run test:unit # unit tests (node --test)
npm run test:e2e  # E2E tests (Playwright)
```
